# Pi + Obsidian: персональный учебный харнесс

Проектная конфигурация [Pi](https://github.com/earendil-works/pi) для занятий с заметками в Obsidian. Репетитор выясняет, что ученик уже понимает, строит маршрут по предпосылкам, задаёт проверочные вопросы и продолжает занятие с учётом прошлых ответов. Ответы и объяснения записываются в обычный Markdown; интерактивные иллюстрации можно открыть прямо в Obsidian.

## Состав

- `.pi/skills/` — репетитор, диагностика, профиль ученика, визуализация и проверка понимания.
- `.pi/extensions/` — учебное состояние, квизы, журнал Markdown, источники и инструменты для SVG/HTML.
- `.pi/agents/` — вспомогательные агенты для исследования, схем и проверки занятий.
- `.obsidian/snippets/` — оформление учебного журнала и широкой заметки.
- `.pi/tests/` — тесты расширений, не содержащие реальные учебные сессии.

## Быстрый старт

1. Установите Pi с пакетом `@earendil-works/pi-coding-agent` и Obsidian. Откройте **новое хранилище Obsidian** в каталоге клонированного репозитория.
2. В Obsidian включите CSS snippets `md-log-callouts` и при желании `wide-note`. Для интерактивных блоков `artifact` установите сторонний [Artifact Embed](https://community.obsidian.md/plugins/artifact-embed) через каталог плагинов Obsidian.
3. Запустите `pi` из корня репозитория. Создайте заметку в этом хранилище и подключите её командой `/md-log /абсолютный/путь/к/заметке.md`.
4. Вызовите `/learn-profile`, чтобы заполнить свой профиль, затем `/teach` или `/probe` для занятия и диагностики. Для отдельной картинки доступна команда `/visual`.

Pi сохраняет личный профиль и ход обучения в `.alvar/`, активный путь к заметке — в `.pi/mdlog.json`, а созданные иллюстрации — в `visuals/`. Эти каталоги и файлы не входят в Git. Для смены заметки снова вызовите `/md-log`.

Тесты расширений: `sh .pi/tests/run.sh` (нужны Pi и Bun). Они проверены с установленным у автора пакетом Pi; при изменении API расширений может понадобиться адаптация.

## Приватность

Репозиторий содержит только повторно используемый код, инструкции и CSS. В нём нет PDF, конспектов, профилей учеников, базы занятий, истории Obsidian, личных путей и результатов диагностики. `.gitignore` по умолчанию исключает новые заметки и состояние хранилища. Перед публикацией собственных изменений проверяйте `git status` и `git diff --cached`.

Методика вдохновлена материалом Eero Alvar [How I Use AI to Learn Things](https://youtu.be/kzcI5F4tGiU); сведения об авторах заимствованных навыков сохранены в их metadata. Плагин Artifact Embed устанавливается отдельно и не входит в этот репозиторий.
