# Проверка харнесса

## Автоматические проверки

```sh
sh .pi/tests/run.sh
node .pi/tests/runtime-smoke.mjs .
```

Первая команда использует реальные установленные пакеты Pi через Bun и временные базы, но имитирует UI и ответы ученика. Вторая загружает расширения и skills через настоящий SDK Pi в отдельном временном vault без обращения к модели. Нужен Pi в PATH; проверенная версия 0.87.1.

94 проверки покрывают, в частности: оценку реального ответа, отделение помощи и самостоятельности, изоляцию учеников, replay/idempotency, ширину диагностики по зависимым ветвям, сохранение формата после двух успехов, help/return, смену цели, переименование темы, версионирование и сохранность плана, противоречащие данные, давность, ordinary-message evidence, HTML/Mermaid delivery, сбой записи и смену заметки. Прежние проверки не отменены: обновлены ожидания там, где поведение сознательно исправлено.

## Проверка с моделью

```sh
node .pi/tests/runtime-smoke.mjs /path/to/harness PROVIDER MODEL medium
```

Команда делает реальные запросы через уже настроенный аккаунт Pi. Копирует только extensions/skills/agents в временный vault, создаёт вымышленный профиль и пустую заметку. Личные конспекты и база не копируются. Учётные данные читаются в память и не входят в трассу. По умолчанию глобальные инструкции и сторонние skills исключены, subagent/bash не активны; сетевые источники не входят в задачу. Это контролируемый стенд, не полная копия персональной конфигурации.

Сценарий: запросить карту скользящего среднего и три варианта; первый ответ UI — «не знаю», последующие вопросы отменяются; затем отдельно попросить подробное объяснение чередующегося сигнала без нового вопроса. Ограничение — 45 tool calls и 4 минуты. trace.json, report.json и lesson.md остаются в напечатанном временном каталоге. Проверяйте timedOut, notifications, ошибки tool_execution_end и сам конспект: completed обозначает завершение запуска, не прохождение педагогических критериев.

Для A/B запускайте один и тот же script с двумя исходными каталогами, одним provider/model/reasoning, неизменным сценарием. Сохраняйте commit/hash исходников. После сравнения одинакового харнесса можно менять только модель или reasoning. Не приписывайте разницу модели, если менялись инструкции или начальная база.

## Наблюдение 2026-09-27

На openai-codex/gpt-6-sol, medium, Pi 0.87.1 сравнивались исходная версия 6088f26 и исправленная версия с новым договором, планом и доставкой. По одному запуску, без статистической оценки:

| Наблюдение | Исходная версия | Исправленная |
| --- | --- | --- |
| Запрошенная графическая карта | Только текстовый маршрут | HTML, 8 областей, объяснения зависимостей, 3 занятия |
| Первый согласованный вопрос | Анонс без вопроса | Квиз с 3 вариантами и сохранённым ответом |
| Объяснение по отдельной просьбе | Числа и HTML | Числа, промежуточные переходы и HTML |
| Новая самостоятельность после объяснения | Не заявлена | Не заявлена |

В новом запуске валидатор отклонил план с необъяснёнными рёбрами; модель дополнила его. Также модель ошибочно вызвала assistance без questionId вместо instruction; событие не было принято. По этому наблюдению уточнены описание инструмента, постоянная политика и ошибка с правильным действием. Повторяемость педагогического поведения и автоматическое исправление каждого ошибочного вызова не гарантируются. Изменения источников плана, масштабирования и пояснений инструмента после этого прогона проверены детерминированно и через загрузчик, без повторного полного A/B.

Визуально проверена синтетическая карта в браузере. В отдельной локальной проверке копия существующего журнала восстановилась с тем же числом событий; персональные трассы и база в репозиторий не включаются.

Для углублённой оценки: несколько независимых повторов, одинаковые зафиксированные ответы ученика, просмотр эффективных инструкций и чтений файлов. Оценивайте сохранение предмета вопроса, нужные промежуточные связи, конкретное применение приёма и выполненный следующий шаг. Длина текста и количество названных техник не заменяют эти критерии. Реальный учебный эффект требует наблюдения за реальным обучением.
