# Стиль досок в Obsidian

Активная тема при настройке: Vanilla AMOLED Color, accentColor #9a5151, wide-note расширяет заметку до 95%. Источники: `.obsidian/appearance.json`, `.obsidian/themes/Vanilla AMOLED Color/theme.css`, `.obsidian/snippets/wide-note.css`. При просьбе сменить стиль сверяй актуальные настройки; не перечитывай CSS на каждом ходе.

## Внешний вид

Доска — часть конспекта: чёрный фон, едва выделенные поверхности, спокойные тонкие границы, ясная типографика. Реальные CSS-переменные Obsidian имеют приоритет над запасными цветами. Не используй фиксированную тёмную палитру поверх светлой темы.

- Фон: `var(--background-primary, #000)`; панели: `var(--background-secondary, #080808)` или `var(--code-background, #111)`; граница: `var(--background-modifier-border, #333)`.
- Текст: `var(--text-normal, #ddd)`; вторичный: `var(--text-muted, #aaa)`; шрифт: `var(--font-text, system-ui)`; код: `var(--font-monospace, monospace)`. Основной размер `var(--font-text-size, 18px)`, line-height 1.5–1.6. Не уменьшай подписи ради втискивания сложной схемы.
- Акцент управления: `var(--interactive-accent, #9a5151)`. Для данных допустимы дополнительные `--color-blue`, `--color-green`, `--color-orange`; цвет имеет смысл и сопровождается подписью/формой. Бордовый не используй как единственный тонкий след графика на чёрном.
- Обычно достаточно одного акцента плюс цветов реально сравниваемых объектов. Без декоративного неона, градиентов, стекла, больших теней, пёстрых карточек и огромных баннеров.
- Внешнюю карточку и её заголовок уже рисует плагин. Не дублируй тот же заголовок и рамку внутри HTML. Пространство используй под сам опыт, а не под интерфейс демосайта.
- Отступы порядка 16–24px, группировка по смыслу, скругления `var(--radius-m, 8px)`. На узком экране располагай элементы вертикально, без горизонтальной прокрутки. Не рассчитывай на ширину всего окна Obsidian.
- Кнопки с понятными глаголами, видимый focus, доступные label у контролов. Движение только помогает увидеть изменение; учитывай prefers-reduced-motion. Важные сведения не прячь только в hover.

## Проверка

Проверь исходное состояние и крайние значения, подписи, контраст, узкую ширину и фактическую высоту блока. Предпочитай компактный кадр без внутреннего скролла; длинное объяснение разбивай на новые кадры в заметке. Не объявляй внешний вид проверенным, если прочитан только код. Для окончательной проверки нужна отрисовка в Obsidian с темой; обычный браузер проверяет только запасные стили и поведение.

Artifact Embed переносит CSS-переменные, а не селекторы темы/сниппетов. Поэтому задавай стили элементов явно через переменные. Локальная поправка theme bridge передаёт также --red/--orange/--yellow/--green/--purple/--frost, от которых зависят цвета заголовков этой темы; обновление плагина может заменить эту поправку.
